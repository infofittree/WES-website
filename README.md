## 🚀 Live Demo & Deployment

This repository is built with 100% static web technologies and is pre-configured for instant deployment on **GitHub Pages**.

### Quick GitHub Pages Setup
1. In your GitHub repository, go to **Settings** > **Pages** (under the *Code and automation* section).
2. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` (or `master`) and folder `/ (root)`.
   - Click **Save**.
3. Within 1–2 minutes, your website will be live at:
   `https://<your-username>.github.io/WES-website/`

## ✨ Features & Architecture

- **Performance-First**: Multi-format `<picture>` tags with WebP compression for 96%+ network payload reduction and zero Cumulative Layout Shift (CLS).
- **Security Hardened**: Strict Content Security Policy (CSP), anti-bot honeypot protection, verified Subresource Integrity (SRI) hashes, and reverse-tabnabbing mitigations.
- **Glassmorphic Industrial Aesthetic**: Dark-mode industrial aesthetic, emerald ambient accents, bento grids, and responsive desktop/tablet/mobile layouts.
- **Fully Accessible**: WCAG 2.1 compliant color contrast ratios and explicit `aria-label` tags for screen readers.
